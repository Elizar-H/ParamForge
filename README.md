# ParamForge

Настольное приложение Windows для втулки с буртиком. По размерам детали формирует маршрутную карту, операционную карту и управляющую программу.

## Запуск

1. Откройте `Запустить.cmd` или `release/ParamForge/ParamForge.exe`.
2. Измените размеры в полях слева или нажмите на нужный размер на чертеже. В редакторе размера можно изменить номинал и отклонения. Enter подтверждает ввод, Esc отменяет.
3. Нажмите **«Сформировать документы»** и выберите папку.

Приложение создаёт новую подпапку «Документы втулки», сохраняя существующие комплекты. В ней ровно три файла:

- `Маршрутная карта.docx` — МК на основе формы 1 ГОСТ 3.1118-82.
- `Технологическая карта.docx` — операционная карта 010 на основе форм 3 и 2 а ГОСТ 3.1404-86.
- `Управляющая программа.nc` — программа операции 010 для выбранного профиля AxiOMA Control.

На чертеже показаны номинальные размеры. Подтверждённые отклонения сохраняются в параметрах; координаты обработки рассчитываются по середине поля допуска с округлением до 0,001 мм. Параметры заготовки, проходов и режимов доступны через отдельную команду. Сохранение и открытие вариантов JSON находится в меню «Файл»; JSON не входит в комплект документов.

## Границы обработки

УП покрывает только операцию 010: наружное точение и растачивание подготовленной полой заготовки. Подготовка 005, отрезка и второй установ с доводкой заднего торца 020, контроль 030 остаются вне УП. Осевая цепь учитывает отдельные припуски, полосу реза, коридор до кулачков и фактическую длину зажима. Исходный полуфабрикат полый, его отверстие существует до 010.

Программа использует ограниченное подмножество AxiOMA Control по руководству программиста 2025 года. Выбран ручной вызов инструментов `T1 D1 M66`, `T2 D1 M66`, диаметральный X `G10 X1`, подача на оборот `G95`, непрерывная СОЖ `M8/M9`. Настройка оси X, таблица инструментов, G54, M-функции и закрепление зависят от конкретного станка. Выполнена только статическая программная проверка. Прогон в эмуляторе AxiOMA и на оборудовании не проводился.

Происхождение исходных значений и технические ограничения описаны в [CONFIGURATION.md](docs/CONFIGURATION.md), исходный техпроцесс и оснастка — в [PROCESS_PROFILE.md](docs/PROCESS_PROFILE.md). Правила изображения — в [DRAWING_RULES.md](docs/DRAWING_RULES.md).

## Сборка

C# / .NET 10, Windows Forms. Для запуска нужен .NET Desktop Runtime 10; браузер, Python и Word для формирования документов не требуются. SDK закреплён в `global.json` на 10.0.402.

```powershell
.\scripts\build.ps1
# Регрессионные проверки ядра отдельно:
dotnet run --project src/Kontur.Tests -c Release -- --report qa/tests.json
# Проверка окна приложения с сохранением изображений:
release/ParamForge/ParamForge.exe --smoke-output qa/ui
```

Карты содержат редактируемые таблицы Word. Неизвестные коды, подписи, нормы времени и производственные реквизиты оставлены пустыми. Полное заполнение производственного комплекта ЕСТД не заявляется. Исходные беседы, личные материалы и текст диплома хранятся отдельно от репозитория.
