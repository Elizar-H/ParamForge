# Проверка 2.13.1

## Настройки

«Применить» доступна только при несохранённых изменениях. После успешного применения кнопка неактивна и подписана «Применено». Новая правка возвращает активное состояние. Возврат к сохранённому числу либо сохранённому режиму заготовки убирает лишнее применение. Некорректный ввод сохраняет активную кнопку и сообщение об ошибке.

Применение по Ctrl+Enter также не выполняется повторно без изменений. Сохранены объединение правок настроек с актуальной геометрией и восстановление ручных размеров заготовки после просмотра расчётного режима.

## Комплект выпуска

Добавлен `scripts/package-release.ps1`: автономная Windows x64, архив исходников из того же коммита и SHA-256 обоих архивов. Скрипт отказывается упаковывать незакоммиченные изменения. Порядок подготовки описан в [RELEASING.md](RELEASING.md).

Архив приложения проверяется распаковкой и запуском из отдельной папки; соответствие исходников фиксируется коммитом и контрольными суммами. Результаты фактической упаковки и запуска сохраняются отдельно с комплектом выпуска.
