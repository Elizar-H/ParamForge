# Техническая проверка 2.13.2

Дата: 1 ноября 2026 года. Проверялись расчёты, ввод, файлы, интерфейс, структура исходников и выпуск автономной программы.

## Исправленные ошибки

1. **Ошибка создания дескриптора при запуске.** Воспроизведена на втором мониторе: первый работал при 150%, второй при 100%. Изменение шрифта во время создания `TabControl` меняло `Padding`, а его setter пересоздавал ещё не готовое окно. Обновление отступов теперь отложено до готовности дескриптора. Проверены оба монитора и перенос между ними. Причина согласуется с реализацией [TabControl в .NET 10](https://github.com/dotnet/winforms/blob/v10.0.0/src/System.Windows.Forms/System/Windows/Forms/Controls/TabControl/TabControl.cs).
2. **Скрипты Windows PowerShell 5.1.** Исправлены кодировка русских строк и несовместимые параметры команд. Сборка, проверки и упаковка выполняются штатным PowerShell Windows.
3. **Недопустимые символы реквизитов.** Непарные суррогаты и символы, запрещённые XML, отклоняются до экспорта DOCX. Обычный Unicode сохраняется.
4. **Обрезка длинных реквизитов Word.** В узких однострочных графах фамилии и материала длинный текст укладывается в ширину строки; короткие значения сохраняют естественную ширину. Одного `tcFitText` оказалось недостаточно: Word мог переносить последние символы в невидимую строку. Проверено полное размещение значений предельной длины.

Диагностика аварии записывает журнал в `%LOCALAPPDATA%\ParamForge\Logs` с запасным каталогом `%TEMP%\ParamForge\Logs`. Если запись невозможна, сообщение не обещает несуществующий файл. Для текста УП используется общий шрифт приложения вместо нового экземпляра при каждом открытии вкладки.

## Выпуск и границы проверки

Упаковка проверяет сам ZIP: распаковывает, запускает EXE на каждом подключённом мониторе, открывает вкладки, меняет ЧПУ, сохраняет и открывает JSON, создаёт две карты и MPF. Пути установленного .NET заменены пустым каталогом. Сценарий включён в GitHub Actions; обычный запуск выполняется без параметров. Исходники архивируются из того же чистого коммита, что и программа; прилагается SHA-256.

Это статическая проверка УП операции 010. Прогоны в AxiOMA, SinuTrain и на станке не выполнены. Проверяющий модуль не заменяет моделирование столкновений, съёма материала и наладку. Остальные операции маршрута не включены в УП. Расчётная заготовка не подбирается из складского сортамента. Карты не означают полностью заполненный производственный комплект ЕСТД.
