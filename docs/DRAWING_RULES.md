# Изображение втулки

Приложение показывает один полный продольный разрез осесимметричной втулки с буртиком и ступенчатым сквозным отверстием. Масштаб автоматически подбирается по окну; изображение не является отдельным конструкторским документом.

ГОСТ 2.305-2008 различает разрез (п. 4.7, в плоскости и за ней) и сечение (п. 4.8, только плоскость). Пункт 7.10 и рисунок 41 предписывают разрез для сечения, распадающегося на самостоятельные части. Поэтому прежнее изображение двух заштрихованных областей без задних кромок заменено разрезом.

Для выбранной втулки задние половины круговых кромок проецируются в видимые вертикальные отрезки на левом торце x=0, уступе x=L−h и правом торце x=L. Эти отрезки проходят через изображение отверстия, но не обозначают добавленный материал: центральный просвет остаётся незаштрихованным. Это геометрический вывод для данной формы, а не буквальное требование ГОСТ о трёх линиях.

Видимые кромки — сплошные основные линии, размерные, выносные и штриховка — тонкие, ось — штрихпунктирная тонкая (ГОСТ 2.303-68, п. 2, таблица 1). Области одного материала имеют одинаковое направление и шаг штриховки (ГОСТ 2.306-68, п. 5–6).

Обычные диаметры заданы вертикальными размерными линиями с двумя стрелками. При тесном расположении допускается вынесение размера наружу. Размерные числа читаются без пересечения с контурами; принципы ГОСТ 2.307-2011, п. 5.1, 5.6, 5.8, 5.11, 5.24, 5.31, 5.38. Полки сами по себе не запрещены (п. 5.27, 5.30), но для обычной геометрии они не нужны.

По запросу пользователя главный чертёж показывает только номиналы. Отклонения не удалены из модели и доступны в редакторе. При отображении симметричного допуска он должен стоять в строке с номиналом той же высотой шрифта (п. 6.6); асимметричные отклонения располагаются выше и ниже с опущенным нулём.

В профиле 2.3 корневые сопряжения показаны номинальным радиусом 0,4 мм в масштабе; если дуга меньше пикселя, её не увеличивают искусственно. Допустимая галтель R≤0,5 принята проектом, а не прочитана с исходного фото. Контрольные размерные привязки остаются к теоретическим плоскостям; h измеряют на плоскости уступа вне галтели. Дополнительный размер R не превращён в восьмое редактируемое поле.
