# ParamForge 2.13.2

Исправлен запуск на мониторах с разным масштабом Windows. В 2.13.1 это могло приводить к сообщению «Ошибка при создании дескриптора окна» сразу после открытия EXE.

## Скачать и запустить

1. Скачайте **ParamForge-2.13.2-win-x64.zip** из вложений выпуска.
2. Распакуйте архив целиком в обычную папку.
3. Откройте **ParamForge.exe**.

Windows x64. Установка .NET, Python или Word для работы программы не требуется. Word или совместимый редактор нужен для просмотра DOCX. Архив **source.zip** предназначен для изучения и сборки исходников.

## Изменения и проверки

- Проверен запуск на мониторах 100% и 150% и перенос окна между ними.
- 430 проверок ядра и 478 проверок интерфейса, включая 400 вариантов детали для каждого ЧПУ.
- Недопустимые символы отклоняются до создания Word-файлов; исправлено размещение длинных реквизитов.
- Карты проверены в Word на А4: обычные и предельные значения, восемь страниц.
- Скрипты совместимы с Windows PowerShell 5.1. Упаковка автоматически проверяет запуск EXE из ZIP и экспорт трёх файлов.
- Исходники и EXE подготовлены из одного коммита. Контрольные суммы — в `SHA256SUMS.txt`.

Подробности: [техническая проверка](https://github.com/Elizar-H/ParamForge/blob/v2.13.2/docs/VALIDATION_2.13.2.md).

УП охватывает операцию 010. Выполнена статическая проверка; прогоны в SinuTrain, AxiOMA и на оборудовании пока не проводились.
