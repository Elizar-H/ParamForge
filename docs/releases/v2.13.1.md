# ParamForge 2.13.1

Приложение для подготовки токарной обработки втулки с буртиком: параметры детали, чертёж, переходы, траектория и комплект документов.

## Скачать и запустить

Скачайте **ParamForge-2.13.1-win-x64.zip**, распакуйте и откройте **ParamForge.exe**. Отдельная установка .NET не нужна. Папка `examples` содержит контрольные варианты проекта.

**ParamForge-2.13.1-source.zip** содержит исходники той же версии. Для сборки требуется .NET SDK 10.0.402; команды проверки и сборки описаны в README и CONTRIBUTING. Контрольные суммы архивов находятся в SHA256SUMS.txt.

## Изменения

- Настройки и траектория открываются закрываемыми вкладками. Сохраняются незавершённые правки при переключении вкладок.
- Кнопка «Применить» включается при правке. После успешного сохранения становится серой с подписью «Применено». Ошибка не отмечается как успешное применение.
- Ошибки под параметрами ведут к соответствующему полю. Для отверстия заготовки показаны ограничения по оправке, отводу и припуску.
- Допуски включены при запуске. В настройках работает переход по полям с клавиатуры.
- Заготовка и зажим в траектории включаются по желанию. Стрелки показывают направление рабочих и холостых движений.
- Уточнены рамки и табличная структура Word-карт.

## Проверка и ограничения

Выполнены сборка, проверки стиля, расчётов, согласования УП и карт, а также проверки интерфейса Windows Forms. Подробности — в `docs/VALIDATION_2.13.1.md` и предыдущих журналах проверки.

Поддерживается семейство «втулка с буртиком». Формируются МК, операционная карта и УП для AxiOMA Control либо SINUMERIK 840D sl. УП охватывает операцию 010; переустановка и задний торец относятся к последующему маршруту. Просмотр траектории статический. Прогоны в SinuTrain и на станке пока не проводились.
