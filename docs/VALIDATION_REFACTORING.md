# Проверка изменения структуры от 30 октября 2026 года

Рефакторинг выполнен для ParamForge 2.11.0. Версия расчётного результата сохранена: её изменение само по себе меняет идентификатор проекта и текст УП. Новых технологических возможностей этот выпуск не добавляет.

## Что изменено

- Исходники сгруппированы по обязанностям: модели, параметры, обработка, ЧПУ, документы, сохранение, окна, рисование и элементы управления.
- Из Engine выделены ParameterSchema, ParameterValidator, OperationCatalog, InspectionPlan и MachiningPlanBuilder.
- AxiOMA и SINUMERIK реализуют собственную часть форматирования; общий LinearPostprocessor нумерует кадры и сопоставляет движения переходам.
- Основной файл MainForm уменьшен с 751 до 120 строк. Части представления распределены по именованным областям; чтение числового черновика, форматирование и общие сообщения выделены в отдельные классы.
- Проверки ядра сгруппированы по функциям вместо названий версий. Проверки окон вынесены в отдельный Kontur.Desktop.Tests, обычное приложение больше не содержит UiSmoke.
- Добавлены .editorconfig, проверка стиля в сборке, scripts/check.ps1, карта архитектуры и правила работы с кодом.

Это организация по обязанностям и зависимостям. Формальная сертификация по стандарту или применение обязательного для всех WinForms шаблона не заявляются. Основания и источники перечислены в [ARCHITECTURE.md](ARCHITECTURE.md).

## Проверки

Сборка четырёх проектов завершена с 0 ошибками и 0 предупреждениями. Пройдены проверки форматирования и выбранных правил стиля через dotnet format --verify-no-changes.

Ядро: 423/423 проверки, 175238 утверждений. Сохранены названия проверок, условия, проверки совместимости, наборы ошибок и состав выпуска.

Интерфейс: 421/421 проверка из отдельного тестового проекта. Отчёт: `qa/ui-20261030-210132-98d6a275/ui-smoke.json`. Фактический DPI 144; сохранены проверки номиналов, допусков, перетаскивания, клавиатуры, выбора ЧПУ, обновления траектории, минимального окна и моделируемых масштабов текста. Снимок нового тестового запуска просмотрен: вид траектории сохранён.

Дополнительно до изменения исходников и после него сняты контрольные результаты для семи вариантов с каждым из двух ЧПУ: исходный, расчётная заготовка, короткий, широкий, стандартные/ручные отклонения и два недопустимых варианта. Все 14 полных сериализованных результатов расчёта совпали по SHA256. Для десяти допустимых вариантов совпали все 40 файлов: десять УП, двадцать Word-карт и десять JSON параметров. Сравнивались байты файлов, а не только числа или имена.

Новая визуальная проверка страниц Word не выполнялась: вёрстка не менялась, байты двадцати контрольных DOCX совпали. Предыдущая визуальная проверка описана в [VALIDATION_2.10.md](VALIDATION_2.10.md). Испытаний на станке, в AxiOMA или SinuTrain этот рефакторинг не добавляет.

## Воспроизведение

```powershell
.\scripts\check.ps1
.\scripts\check.ps1 -Ui
.\scripts\build.ps1
```

Для ручного запуска проверок окон используется отдельный проект и новый каталог:

```powershell
dotnet run --project src/Kontur.Desktop.Tests -c Release -- --smoke-output qa/ui-new-run
```

Исторические отчёты относятся к старым сборкам и сохраняют прежние команды. Текущие команды находятся в README и CONTRIBUTING.
