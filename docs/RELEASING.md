# Сборка Windows x64

```powershell
.\scripts\check.ps1 -Ui
.\scripts\package-release.ps1 -SkipChecks
```

По умолчанию архив приложения, отдельный архив исходников и SHA-256 записываются в `build/packages`. Скрипт использует общую конфигурацию `windows-release`; `PARAMFORGE_WORK_ROOT` меняет папку отчётов и упаковки, `-OutputDirectory` — папку готовых архивов. Архив исходников содержит текущий C++/Qt-проект, включая `CMakePresets.json`, значок и ресурсы сборки, без локальных результатов и старого приложения C#. Сборка содержит Qt DLL, платформенный плагин Windows и локальные распространяемые библиотеки MSVC. Установленные Qt, Visual Studio, .NET и Word для запуска не требуются.

Скрипт распаковывает готовый ZIP в папку с пробелом и проверяет EXE с очищенными путями к средствам разработки на втором мониторе, если он доступен. Сценарий открывает три раздела, проверяет OpenGL, сохраняет и повторно открывает JSON, выпускает две Word-карты и две MPF.

Перед публикацией отдельно просмотреть Word-карты и интерфейс. Версия задаётся в CMake и передаётся приложению при сборке. Выпуск локального архива не создаёт коммит, тег или релиз GitHub. Публикация выполняется только по поручению пользователя.
