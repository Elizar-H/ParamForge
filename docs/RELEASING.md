# Сборка Windows x64

Перед упаковкой зафиксируйте изменения в Git. Скрипт требует чистый рабочий каталог; локальные `build`, `app` и настройки редактора не мешают сборке, если исключены из Git.

```powershell
.\scripts\check.ps1 -Ui
.\scripts\package-release.ps1 -SkipChecks
```

По умолчанию архив приложения, отдельный архив исходников и SHA-256 записываются в `build/packages`. Скрипт использует общую конфигурацию `windows-release`; `PARAMFORGE_WORK_ROOT` меняет папку отчётов и упаковки, `-OutputDirectory` — папку готовых архивов. Исходники упаковываются командой `git archive` из зафиксированного коммита; игнорируемые файлы внутри `src` и других папок в архив не попадают. Коммит и чистота каталога проверяются повторно после упаковки. Сам проект из архива можно собрать без Git. Сборка содержит Qt DLL, платформенный плагин Windows и локальные распространяемые библиотеки MSVC. Установленные Qt, Visual Studio, .NET и Word для запуска не требуются.

Скрипт распаковывает готовый ZIP в папку с пробелом и проверяет EXE с очищенными путями к средствам разработки на втором мониторе, если он доступен. Сценарий открывает три раздела, проверяет OpenGL, сохраняет и повторно открывает JSON, выпускает две Word-карты и две MPF.

Перед публикацией отдельно просмотреть Word-карты и интерфейс. Версия задаётся в CMake и передаётся приложению при сборке. Выпуск локального архива не создаёт коммит, тег или релиз GitHub. Публикация выполняется только по поручению пользователя.

Для релиза нужны успешная проверка GitHub Actions на выбранном коммите, совпадение исходников с тегом и проверка скачанных вложений по SHA-256. Основная ссылка ведёт на `ParamForge-<версия>-win-x64.zip`; архив `source.zip` предназначен для разработки.
