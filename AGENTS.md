# ParamForge

- Актуальный проект — этот репозиторий: C++20, Qt 6.12, Qt Widgets, CMake. Перед изменениями изучить код и `docs/ARCHITECTURE.md`.
- Расчёты отделять от интерфейса. Карты и УП должны соответствовать одному результату; траекторию восстанавливать из сформированного G-кода.
- Интерфейс: сдержанный серый минимализм, без лишних подписей и дублей. Сохранять удобный ввод, клавиатурную навигацию и видимость геометрии при редактировании.
- README: короткое описание, скачивание, скриншот. Описание релиза: скачать и запустить. Служебные отчёты туда не добавлять.
- Проверки: `scripts/check.ps1`, при изменениях интерфейса — `-Ui`; Word-карты проверять визуально, включая А4 и рамки. Статическую проверку УП не называть прогоном на станке.
- Выпуск: автономный Windows x64 ZIP; проверять именно распакованный архив. Git и публикация — по поручению пользователя.
- Проект открывается в Visual Studio как папка CMake. Общие конфигурации находятся в `CMakePresets.json`: Debug, Release и Checks. Обычные Debug/Release не собирают тесты. Не создавать копию `.sln` со ссылками на внешние сборочные проекты.
- Исходники, настройки и тесты хранить в репозитории. Результаты сборки, проверок, промежуточные файлы и локальные архивы — в игнорируемой папке `build`; готовое приложение — в игнорируемой папке `app`. Для отчётов и упаковки на CI допустим `PARAMFORGE_WORK_ROOT`. Qt — установленный SDK, по умолчанию `C:\Qt\6.12.0\msvc2022_64`, другой путь задаётся через `PARAMFORGE_QT_ROOT`. Зависимость проекта от папок Codex недопустима. Старые исходники C# сохранены отдельно; не возвращать параллельное приложение или зависимость от .NET.
